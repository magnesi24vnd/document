Hạ tầng Node riêng & Cơ chế Gas Token

Quy trình DevOps/CLI khởi chạy Node trên Ubuntu VPS và cơ chế chuyển đổi Testnet → Mainnet để VNKR trở thành Native Gas Token.

1. Quy trình DevOps / CLI khởi chạy Node

Hệ thống được triển khai trên kiến trúc EVM-Compatible App-chain (sử dụng công nghệ tương đương Polygon CDK / Erigon Client) để giải quyết bài toán tự chủ hoàn toàn mạng lưới và biến VNKR thành Native Gas Token — đóng vai trò như ETH trên Ethereum.

Bước cài đặt môi trường

  1. Cài đặt Docker, Docker Compose và công cụ cốt lõi trên Ubuntu VPS

    Chuẩn hóa môi trường hệ thống Cấp độ 4.

    sudo apt update && sudo apt upgrade -y
sudo apt install curl iptables build-essential \
  git wget jq make gcc nano tmux htop -y
  2. Khởi tạo thư mục định tuyến riêng cho mạng VNKR 
    mkdir -p /var/www/core/vnkr-node && cd /var/www/core/vnkr-node
  3. Cấu hình tệp docker-compose.yml — Sequencer Node & RPC Node độc lập 
    cat << 'EOF' > docker-compose.yml
version: '3.8'
services:
  vnkr-sequencer:
    image: ghcr.io/polygon/erigon:latest
    container_name: vnkr-sequencer-node
    restart: always
    ports:
      - "8545:8545"
      - "8546:8546"
      - "30303:30303"
    volumes:
      - /var/www/core/vnkr-node/data:/datadir
    command:
      - --datadir=/datadir
      - --http
      - --http.addr=0.0.0.0
      - --http.vhosts=*
      - --http.corsdomain=*
      - --http.api=eth,net,web3,personal,miner
      - --ws
      - --ws.addr=0.0.0.0
      - --ws.api=eth,net,web3
      - --networkid=78968
      - --mine
      - --miner.etherbase=0xYourValidatorWalletAddressHere
EOF
  4. Khởi chạy Node ở chế độ nền qua CLI 
    docker compose up -d
  5. Kiểm tra trạng thái đồng bộ khối và kết nối RPC 
    curl -X POST -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}' \
  http://localhost:8545
Network ID: Mạng VNKR App-chain sử dụng --networkid=78968 — đây là Chain ID riêng biệt, không xung đột với các mạng EVM công khai khác (Ethereum: 1, BSC: 56, Polygon: 137).

2. Cơ chế chuyển đổi Testnet → Mainnet & Gas Token

Giai đoạn Testnet

Phát hành Test-VNKR không giới hạn thông qua Faucet Portal công khai để cộng đồng kiểm thử hợp đồng thông minh, giao dịch game-fi và tải hệ thống. Truy cập faucet.vnkr.vn.

Giai đoạn Mainnet

Tùy chỉnh trực tiếp trong tệp genesis.json của mạng lưới để định nghĩa VNKR là tài sản gốc (Native Token). Mọi giao dịch gọi hàm, chuyển khoản, hay tương tác dApp đều bắt buộc trừ trực tiếp VNKR làm phí giao dịch, tạo động lực tích lũy và thanh khoản tự nhiên.

⚠️ Lưu ý triển khai: Trường --miner.etherbase trong docker-compose.yml phải được thay thế bằng địa chỉ ví Validator thực tế trước khi triển khai lên Mainnet. Quản lý khóa riêng tư thông qua HSM (xem Phần 2 — Bảo mật).
